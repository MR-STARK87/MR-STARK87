### ⚔️ EAZE — Custom Programming Language

> *"Pedagogy baked into language design."*

A fully interpreted programming language built from scratch to eliminate syntactic friction for beginners — without sacrificing computational depth.

```
┌─────────────────────────────────────────────────────┐
│  PIPELINE:  Lexer → Parser → AST → Interpreter      │
│                                  └→ Runtime (Scope) │
└─────────────────────────────────────────────────────┘

  eaze > set x to 10
  eaze > if x is greater than 5 then show "big" end
  → big

  Features: variables · conditionals · loops · recursion · arrays
  Testing:  250+ cases · 100% pass rate
  CLI:      REPL with multi-line execution & variable inspector
```

**Stack:** `Java` · `Custom Lexer/Parser` · `AST Execution Engine` · `CLI REPL`

### 🧠 RETRO — AI Learning System

> *"Static notes become an adaptive intelligence."*

A stateful, full-stack AI learning platform that closes the loop between notes, memory, and understanding.

```
┌──────────────────────────────────────────────────────┐

│                                                      │
│  Notes ──────→ Flashcards (spaced repetition)        │
│     │                                                │
│     └──────→ Chat ←──────→ Memory (persistent)       │

  Modules: Rich Notes · AI Flashcards · Contextual Chat
```
