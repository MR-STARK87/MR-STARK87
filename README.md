## `> ls projects/`

<details>
<summary><b>⚔️ EAZE — Custom Programming Language & Execution Engine</b></summary>

<br/>

> *"Eaze integrates pedagogy into language design by reducing syntactic complexity while preserving computational structure."*

A fully custom interpreted programming language built from scratch — designed to eliminate syntax friction for beginners while keeping computational fundamentals intact.

**System Architecture**
```
Source Code
    │
    ▼
 [LEXER] ──────── Tokenization
    │
    ▼
 [PARSER] ─────── AST Generation
    │
    ▼
[INTERPRETER] ─── Execution Engine
    │
    ▼
 [RUNTIME] ─────── Scope & Variable Management
```

**What it does**
- English-like syntax: `set x to 5` · `show x` · `repeat 3 times`
- Full language support: variables, conditionals, loops, functions, recursion, arrays
- CLI REPL with multi-line execution + `vars` inspector
- Beginner-oriented error system
- **250+ test cases · 100% pass rate**

**Stack:** `Java` · `Custom Lexer/Parser` · `AST Design` · `Runtime Engineering`

**Currently Building:** Eaze Studio (Monaco-based IDE) · Eaze Playground · AI explanation layer · `eaze-lang` npm package

</details>

<br/>

> *"Retro transforms static learning into an adaptive system by combining user data, AI reasoning, and persistent memory."*

A full-stack, stateful learning platform that forms a self-improving feedback loop across notes, flashcards, and AI chat.

**The Loop**
```
Notes ──────────► Flashcards
  │                    │
  ▼                    ▼
Chat ◄──── Memory ◄─── AI
  │
  └──────────────► Memory (updates)
```

**Core Modules**
| Module | What it does |

| 📝 Notes | Rich text editor (Quill Delta) · tagging · AI-enhanced |
| 🃏 Flashcards | Manual + AI-generated · spaced repetition · linked to notes |
| 💬 Chat | Session-based · context-aware · note-integrated queries |
| 🧠 Memory Layer | Persistent user context injected into AI prompts *(signature feature)* |
| 🎵 DEN | Pomodoro timer · ambient focus mode · music support |
